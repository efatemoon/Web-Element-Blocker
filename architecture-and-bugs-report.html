4. 架构优化要点

统一监听生命周期（X1 根因）。 将原本分散在「主文档固定注册 / iframe 文档裸注册」的两套逻辑，收敛为单一 _trackDocOn(doc, type, handler, opts) + _untrackDocAll() 注册表，所有文档（含同源 iframe）的监听都在 stopSelection 中被统一注销。addEventListener 对相同函数+类型+capture 自动去重，重复进入同一 iframe 不会累积监听。

选择状态按引用保留（X2）。 覆盖层/iframe 重扫前记录用户已手动勾选的元素引用，扫描后用 findIndex(r => r.el === el) 回填，避免异步重扫丢失人工选择。

大小写归一（X3）。 已封杀域名比较统一 .toLowerCase()，消除大小写不一致导致的「已封杀又可选」展示误导。

未改动架构边界： PanelRegistry（OCP）、StorageService（Proxy 写入端口）、服务层 DIP 接缝均保持不变；仅修复生命周期与状态一致性，未拆分文件、未删除功能。
