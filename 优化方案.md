## 一、真实 Bug（5 个）

### 🔴 Bug 1（P0）：hostnameBlocked LRU 缓存跨 domainSet 污染

**位置**：`BlockEngine.hostnameBlocked()` 被 `isUrlBlocked()` 和 `scanAndBlockDynamic()` 调用

**源码证据**：

```javascript
// hostnameBlocked 中：缓存 key 仅为 host
const cached = this._hostCache.get(host);
if (cached !== undefined) return cached;

// isUrlBlocked 中：同一 host 被两个不同 Set 查询
if (this.hostnameBlocked(absUrl.hostname, this.getDomainSet())) return true;        // Set A
if (genDomainSet.size > 0 && this.hostnameBlocked(absUrl.hostname, genDomainSet)) return true; // Set B
```

**后果**：host 对 Set A 返回 false 后被缓存 → 后续对 Set B 查询同一 host 直接返回缓存的 false → 泛化域名规则对已被精确 Set 查询过的 host 永远失效。

**修复**：

```javascript
static hostnameBlocked(host, domainSet) {
    if (!host || !domainSet || domainSet.size === 0) return false;
    host = String(host).toLowerCase();
    // 用 domainSet 引用做命名空间前缀，隔离两个缓存域
    const cacheKey = (domainSet === this._cachedGenDomainSet ? 'g:' : 'd:') + host;
    const cached = this._hostCache.get(cacheKey);
    if (cached !== undefined) return cached;
    const result = this._rawHostnameMatch(host, domainSet);
    if (this._hostCache.size >= 200) {
        this._hostCache.delete(this._hostCache.keys().next().value);
    }
    this._hostCache.set(cacheKey, result);
    return result;
}
```

### 🔴 Bug 2（P0）：recordNormalPath 使用 Array.includes() → O(N) 热路径

**位置**：`StorageManager.recordNormalPath()`

**源码证据**：

```javascript
if (arr.includes(cleanPath)) return; // Set 语义去重
```

每个未拦截的 fetch/XHR 都触发此方法，`arr.includes` 在 normalPaths 接近 200 条时为 O(200) 字符串比较。

**修复**：内存中维护 Set 镜像：

```javascript
_normalPathSets = {}; // site -> Set<path>

recordNormalPath(site, path) {
    if (!site || !path || typeof path !== 'string' || path.length < 2) return;
    const cleanPath = path.split('?')[0].split('#')[0];
    if (cleanPath.length < 2 || cleanPath === '/') return;
    if (!this._normalPathSets[site]) {
        const allPaths = this._readKey('normalPaths', {});
        this._normalPathSets[site] = new Set(allPaths[site] || []);
    }
    const pathSet = this._normalPathSets[site];
    if (pathSet.has(cleanPath)) return; // O(1) 替代 O(N)
    pathSet.add(cleanPath);
    const allPaths = this._readKey('normalPaths', {});
    if (!allPaths[site]) allPaths[site] = [];
    allPaths[site].push(cleanPath);
    if (allPaths[site].length > 200) {
        const removed = allPaths[site].splice(0, allPaths[site].length - 200);
        removed.forEach(p => pathSet.delete(p));
    }
    this._markDirty('normalPaths', allPaths);
}
```

### 🟡 Bug 4（P1）：_clearSheetRules 逐条 deleteRule(0) → O(N²)

**位置**：`BlockEngine._clearSheetRules()`

**源码证据**：

```javascript
static _clearSheetRules(sheet) {
    if (!sheet) return;
    if (sheet.cssRules) {
        while (sheet.cssRules.length > 0) {
            try { sheet.deleteRule(0); } catch (e) { break; }
        }
    }
}
```

**修复**：

```javascript
static _clearSheetRules(sheet) {
    if (!sheet) return;
    // 快路径：Constructable Stylesheets 用 replaceSync('') 一次性清空
    if (this._useConstructable) {
        try { sheet.replaceSync(''); return; } catch (e) { }
    }
    // <style> 降级路径：直接清空 textContent（触发整表重建，O(1) 调用）
    const owner = sheet.ownerNode;
    if (owner) { owner.textContent = ''; return; }
    // 兜底：从尾部删除（deleteRule(length-1) 无需索引重排，O(1)/条）
    if (sheet.cssRules) {
        while (sheet.cssRules.length > 0) {
            try { sheet.deleteRule(sheet.cssRules.length - 1); } catch (e) { break; }
        }
    }
}
```

### 优化 3：DomainGeneralizer.extractOptimalDomains 中 O(N²) filter → 构建时记录

**现状**：

```javascript

    d.split('.').reverse().slice(0, currentPath.length + 1).join('.') === pathKey
);
```

**方案**：在 Trie 构建时直接记录每个节点覆盖的域名列表：

```javascript
static buildReverseTrie(domains) {
    const root = {};
    domains.forEach(domain => {
        if (!domain || typeof domain !== 'string') return;
        const parts = domain.toLowerCase().split('.').reverse();
        let curr = root;
        parts.forEach(part => {
            if (!part) return;
            if (!curr[part]) curr[part] = { _count: 0, _children: {}, _domains: [] };
            curr[part]._count++;
            curr[part]._domains.push(domain); // ← 构建时即记录
            curr = curr[part]._children;
        });
    });
    return root;
}
// traverse 中直接用 node._children[key]._domains 替代 filter
```
