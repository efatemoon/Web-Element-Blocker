## video-accelerator.user.js 代码简化与 bug 修复

### 隐藏 Bug 修复

1. **网络带宽估算除零保护** (line 98)
   - 问题：当所有性能条目 duration 为 0 时，除以零返回 Infinity
   - 修复：添加 `ms > 0` 保护，返回 0 而非 Infinity

2. **emergencyLoad 网络状态判断扩大** (line 2463)
   - 问题：只检查 `networkState === 3`，漏掉已废弃的网络状态值（如 4=NETWORK_NO_SOURCE）
   - 修复：改为 `networkState >= 3`，覆盖所有错误状态

3. **_onPause 防抖漏判** (line 2026)
   - 问题：seeking 状态下用户按暂停键会误触发 user-pause/DORMANT 逻辑
   - 修复：添加 `!this.isSeeking` 条件

4. **userIntentFirst 双重默认值** (line 2027)
   - 问题：`let user = true` 使 userIntentFirst=false 时行为与设置相反（默认为用户暂停）
   - 修复：改为 `let user = false`，关闭时默认进入 DORMANT

5. **ConfigManager.set 重复调用 load()** (line 372)
   - 问题：同一配置写入后调用两次 load()，浪费且可能不一致
   - 修复：缓存 loaded 结果后复用

6. **_flushSettings 缺少 _updateDependency()** (line 3577)
   - 问题：外部写入配置后不更新依赖提示 UI（如自动降画质依赖提示）
   - 修复：追加 `_updateDependency()` 调用

7. **UIManager._toastT 未声明** (line 3028)
   - 问题：`clearTimeout(this._toastT)` 和赋值访问未初始化属性
   - 修复：在构造函数中初始化 `this._toastT = null`

8. **_collectLocalState 内联空状态对象** (line 2814)
   - 问题：20 行重复的空状态对象定义，与 StateStore._idle() 语义重复
   - 修复：提取模块级 `getIdleState()` 函数，统一复用

9. **healthScore 字符串比较** (line 3750-3751)
   - 问题：`s.sessionState === SessionState.FAILED` 在聚合状态中为字符串 'failed'，不匹配对象值
   - 修复：改用字符串直接比较 `'failed'` / `'recovering'`

10. **_updateFab 字符串比较** (line 3874)
    - 问题：同上，`state.sessionState` 为聚合后的字符串值
    - 修复：改为 `'recovering'` / `'failed'` 直接比较

### 代码简化
