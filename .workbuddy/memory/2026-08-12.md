# 2026-08-12 工作日志

## web-element-blocker.user.js iframe 防线面板 UX 重构（v3.2.0）
- 用户反馈：iframe 防线管理面板与「扫描不可见覆盖层广告」面板在预览、规则选择、展示逻辑上不一致；当前面板把「屏蔽」和「保护」混在一起，不好用。
- 按用户提供的覆盖层扫描面板截图，将 iframe 面板重构为同款逻辑与展示：
  - 统一列表展示帧级 + 帧内元素级记录，按嫌疑分降序排列
  - 每行左侧勾选框、分类标签（广告帧/内容帧/白名单/未知/可疑元素原因）、元素信息、meta（src/选择器/尺寸/z-index）
  - 右侧分数圆环（红/橙/灰），与 OverlayScanPanel 共用 `.gd-score` 样式
  - 工具栏：「只看高风险」「选中高风险」「清空」+ 嵌套深度输入
  - 统计行：`共 N 项 · 广告帧 X · 内容帧 Y · 可疑元素 Z · 已拦截 W · 选中 V`
  - 底部：「同时封杀 iframe 源域名」复选框 + 大红块按钮「拦截选中的 N 个 iframe/元素」
  - 操作按钮组：「深度扫描」「预览效果」「重新扫描」「关闭」
  - 白名单管理独立为底部折叠区，仅保留「已保护的内容帧」列表 + 删除；新增保护入口改为「✅ 保护选中的内容帧」二级按钮，仅当选中内容帧时可用
- 保留原有能力：5s 扫描缓存、EventBus 统计订阅、blockedFingerprints、预览横幅、最大嵌套深度控制、批量拦截+域名封杀
- 监听器泄漏修复同步升级：旧 `renderScanList` 内重复绑定 checkbox/listener 的逻辑被整体替换为面板创建时一次性绑定 `#iframe-list` 容器，渲染只替换子节点；对应回归测试已更新
- 版本号：user.js `3.1.3` → **3.2.0**，meta.js `3.0.3` → **3.2.0**（对齐更新检查）
- 验证：node --check ✅；npx jest ✅ 16 套件/73 用例全绿
